Farmer's Market Price and Sales Tracker

This project is a simple Java program made to help keep track of a farmer's crop details, market price, and sales. We wanted to create something practical while using the basic Java concepts we have learned.

The program allows the user to enter the crop name, available quantity, and current market price. The price can be updated whenever it changes, and the user can also record crop sales. After a sale is recorded, the program calculates the sale amount and updates the remaining quantity.

Features
Enter and view crop details
Update the market price
Record crop sales
Calculate total sales
Check the remaining quantity
Display a final summary
Concepts Used

The project mainly uses the Java concepts covered in our coursework, such as:

Variables and data types
Scanner for taking input
Arithmetic and relational operators
if-else statements
switch statements
while loop
User-defined methods

The main purpose of this project is to understand how the Java concepts we learned can be combined to make a simple working application for a real-world situation.
